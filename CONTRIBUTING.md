# Contributing

Thanks for your interest in improving an [ashlrai](https://github.com/ashlrai)
project. This is the organization-wide default guide; a repository's own
`CONTRIBUTING.md` takes precedence.

## Before you start

- Search existing issues and pull requests first.
- For anything larger than a small fix, open an issue describing the problem
  and proposed approach before writing code.
- Security issues: follow [SECURITY.md](SECURITY.md) instead of opening an issue.

## Making a change

1. Fork the repository and create a branch from the default branch.
2. Follow the setup, build, and test instructions in the repository README.
3. Keep pull requests focused: one logical change per PR, with tests or docs
   updated alongside the code.
4. Make sure the repository's CI checks pass (build, lint, tests).
5. Describe what changed and why in the PR, and link the issue it addresses.
